# Release roadmap

## Current stage

- Public repository established.
- Project scope and planned release contents documented.

## Upon paper publication

1. Release preprocessing and patch-generation code.
2. Release reconstruction, GLCM difference, multiscale integration, and ranking code.
3. Release redistributable training and validation imagery.
4. Release metadata, checksums, and reproduction instructions.
5. Add the final citation and BibTeX entry.

## After the initial release

- Add example commands and a minimal demonstration dataset where possible.
- Add model checkpoints if permitted by size and licensing constraints.
- Track data/code issues through the GitHub issue tracker.
