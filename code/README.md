# Source code

**Release status:** Pending journal publication.

This directory will contain the implementation and reproduction materials for the manuscript. Planned components include:

- image preprocessing and 512 × 512 tiling;
- landform-specific latent diffusion model configuration;
- multiscale image reconstruction;
- local-window normalized GLCM difference calculation;
- multiscale score integration and candidate ranking;
- evaluation against the reference-site inventory;
- figure and table generation scripts.

Environment files and exact dependency versions will be added with the public code release.
